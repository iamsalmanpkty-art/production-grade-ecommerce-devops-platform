<h2> Project Overview</h2>

<p>
This project demonstrates a complete DevOps workflow from source code management to deployment, monitoring, and Kubernetes orchestration.

The objective of this project was to understand how modern applications move from development to production using industry-standard DevOps tools and practices.
</p>

<h2>🔄 CI/CD Workflow</h2>

<pre>
Developer
    ↓
Git Push
    ↓
GitHub Repository
    ↓
GitHub Actions
    ↓
SSH Connection to EC2
    ↓
Docker Build
    ↓
Docker Compose Restart
    ↓
Updated Application
</pre>
